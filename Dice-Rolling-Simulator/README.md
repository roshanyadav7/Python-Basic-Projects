# 🎲 Dice Rolling Simulator

A simple **Dice Rolling Simulator** built with Python.
The program allows the user to choose how many dice to roll, generates random results, calculates the total, and gives the option to roll again.

## ✨ Features

* 🎲 Roll one or multiple dice
* 🔢 Choose the number of dice
* 🎯 Random dice results from 1 to 6
* ➕ Calculates the total of all dice
* 🔄 Option to roll again
* ⚠️ Handles invalid input
* 🛑 Simple option to exit the game

## 🛠️ Technologies Used

* **Python 3**
* `random` module

# 🧠 Python Quiz Game

A simple **Python Quiz Game** that tests the user's basic knowledge of Python through multiple-choice questions.

The game runs in the terminal and provides instant feedback, calculates the final score, and allows the user to play again.

## 📌 Features

* 🐍 15 Python-based quiz questions
* 🔤 Multiple-choice questions (A, B, C, D)
* ✅ Checks whether the answer is correct
* ❌ Displays the correct answer when the user is wrong
* 🛡️ Validates user input
* 📊 Calculates the final score
* 📈 Calculates the percentage
* 🏆 Assigns a grade based on the score
* 🔄 Option to play the quiz again
* 💻 Runs directly in the terminal

## 🛠️ Technologies Used

* **Python 3**
* No external libraries required

## 🎮 How to Play

1. Start the program.
2. Read each Python question.
3. Choose an answer by entering **A, B, C, or D**.
4. The program immediately tells you whether your answer is correct.
5. After all 15 questions, your score and percentage are displayed.
6. You will receive a grade based on your performance.
7. Choose **Y** to play again or **N** to exit.

## 📊 Grading System

| Percentage | Grade | Message                   |
| ---------: | :---: | ------------------------- |
|       100% |   A+  | Excellent! Perfect score! |
|     80–99% |   A   | Great job!                |
|     60–79% |   B   | Good work!                |
|     40–59% |   C   | Keep practicing!          |
|  Below 40% |   D   | You need more practice.   |

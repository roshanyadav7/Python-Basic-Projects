# 🎬 Famous MCU Quote Generator

A simple Python program that generates **famous and memorable quotes from the Marvel Cinematic Universe (MCU)**.

The program randomly selects a quote from a collection of iconic MCU quotes whenever the user enters `quote`. The user can continue generating quotes or type `exit` to close the program.

## ✨ Features

* 🎲 Generates a random famous MCU quote
* 🦸 Includes iconic quotes from MCU characters
* 🔄 Generate multiple quotes without restarting
* ⌨️ Supports case-insensitive commands
* ❌ Handles invalid input
* 🚪 Simple command to exit the program

## 🛠️ Concepts Used

* Python lists
* `random` module
* `random.choice()`
* `while` loops
* `if`, `elif`, and `else`
* User input with `input()`
* `.strip()` and `.lower()`
* `break`
* String formatting

## ▶️ How to Run

Make sure Python is installed on your computer.

Run the following command:

```bash
python mcu_quote_generator.py
```

## 🎮 How to Use

When the program starts, enter:

```text
quote
```

to generate a random famous MCU quote.

Example:

```text
>> I am Iron Man.
```

You can enter `quote` again to generate another random quote.

To exit the program, enter:

```text
exit
```

### Invalid Input

If you enter an invalid command, the program will display:

```text
Invalid input! Please type "quote" or "exit".
```

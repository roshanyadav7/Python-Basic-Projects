# 🎮 Rock-Paper-Scissors

A simple **Rock-Paper-Scissors game** built with Python. The player competes against the computer in a **Best of 5** match.

The project was created to practice Python fundamentals such as functions, loops, conditional statements, lists, user input, and the `random` module.

## 🚀 Features

* 🎮 Player vs Computer
* 🏆 Best of 5 gameplay
* 📊 Score tracking
* 🤖 Random computer choices
* ✅ Input validation
* 🔄 Play again option
* ❌ Quit option
* 🧩 Organized using functions
* 🎯 Final winner announcement

## 🛠️ Built With

* **Python 3**
* **Random Module**

## 🎯 How to Play

1. Choose **rock**, **paper**, or **scissors**.
2. The computer randomly selects its choice.
3. The winner of the round is determined:

   * 🪨 Rock beats Scissors
   * 📄 Paper beats Rock
   * ✂️ Scissors beats Paper
4. The first player to reach **3 points** wins the game.
5. After the game, you can choose to play again.

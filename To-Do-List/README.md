# 📝 To-Do List

A simple command-line To-Do List application built with Python.

This project was created to practice Python fundamentals and basic error handling.

## ✨ Features

* ➕ Add new tasks
* 👀 View all tasks
* ❌ Remove tasks by number
* 🛡️ Handles invalid task-number input
* 🚫 Prevents empty tasks
* 🚪 Exit the application

## 🛠️ Concepts Used

* Lists
* `while` loops
* `for` loops
* `if / elif / else`
* Functions
* `input()`
* `append()`
* `pop()`
* `len()`
* `enumerate()`
* f-strings
* `try / except`
* `.strip()`

## ▶️ How to Run

Make sure Python is installed on your system.

### 1. Clone the repository

```bash
git clone https://github.com/roshanyadav7/Python-To-Do-List.git
```

### 2. Navigate into the project

```bash
cd To-Do-List
```

### 3. Run the program

```bash
python todo.py
```

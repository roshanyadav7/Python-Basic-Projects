# 📝 Word Count Program

A simple Python program that analyzes a sentence and provides basic information about the text.

## 📌 Features

* Counts the total number of words
* Counts the total number of characters
* Counts the frequency of each word
* Handles empty input
* Treats uppercase and lowercase words as the same

## 🛠️ Built With

* **Python**

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in a terminal.
3. Run the program:

```bash
python word_count.py
```

## 💡 Example

```text
========================================
          WORD COUNT PROGRAM
========================================

Enter a sentence: Python is easy and Python is powerful

--- Result ---
Number of words: 7
Number of characters: 37

Word frequency:
python : 2
is : 2
easy : 1
and : 1
powerful : 1
```
